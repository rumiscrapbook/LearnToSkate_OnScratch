# 🛹 Learn to Skate! (Scratch)

An interactive beginner skateboarding tutorial built in **Scratch** and converted into code using **TurboWarp**.

## 📖 About

This project teaches the basic steps of skateboarding through a simple interactive tutorial.
It was created to practise programming with Scratch while making something fun and educational.

## ✨ Features

* 🛹 Introduction to skateboarding
* 👣 Learn the correct stance
* 🚀 How to push and start moving
* ⚖️ Tips for balancing
* ↩️ Basic turning
* 🛑 Safe stopping technique
* 🎮 Interactive scenes and animations

## 🛠️ Built With

* Scratch
* TurboWarp

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project in TurboWarp or Scratch (if applicable).
3. Click the **Green Flag** to start.
4. Follow the tutorial and enjoy learning the basics of skateboarding!

## 📌 Project Goal

The goal of this project was to combine programming with one of my interests by creating a simple 
tutorial that beginners can easily follow.
